# docs/superpowers/ — historical planning and task documents

Like `llm-contexts/` at the repo root, the files under `plans/` and `specs/` here are
point-in-time task specs and plans written during earlier development phases. **None of them are
guaranteed current.** For the authoritative, maintained description of this codebase, see
`/CLAUDE.md` at the repo root. If a file here contradicts CLAUDE.md, CLAUDE.md wins.

This directory has not been individually audited file-by-file — spot checks found references to
component names that were never built (e.g. `BacktestReport/index.tsx`, `StrategyPicker/index.tsx`)
and test files that don't exist, i.e. expected plan/implementation drift. Treat everything here as
a design-history reference, not a spec of the live app.
